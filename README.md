# EduJuegos Costa Rica
Portal educativo estático para GitHub Pages. 12 minijuegos de preguntas sobre Español, Matemáticas, Ciencias, Estudios Sociales e Inglés, con enfoque costarricense. El banco de preguntas inicial es demostrativo (3 por juego), no sustituye una alineación curricular oficial del MEP. Guarda apodo y puntos localmente en el navegador.

## Publicar
1. Crear repositorio en GitHub.
2. Subir `index.html`, `style.css` y `app.js` a la raíz.
3. Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Abrir la URL publicada por GitHub Pages.

No necesita servidor ni dependencias externas. Para ampliar preguntas, editar el arreglo `games` en `app.js`.
